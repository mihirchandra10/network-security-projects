# S10 · Cloud Security: IAM, MFA and Secure Architecture

**Companies:** Open Communication Ltd. (2020 – 2024) · RASA Technologies (2024 – 2025)
**Role:** Manager, Network Solutions & Security / Manager, Infrastructure Solutions

## Security objective
Secure customer workloads on public cloud platforms with identity-based access control and a secure architecture.

## Security controls delivered
| Control | Implementation |
|---|---|
| Cloud security architecture | Designed and implemented cloud security architectures and policies |
| Identity and access management | Configured **IAM roles and policies** following least privilege |
| Multi-factor authentication | Enforced **MFA** for cloud access |
| Secure provisioning | Infrastructure as Code (Terraform), so security settings are consistent and reviewable |
| Secure delivery | CI/CD pipelines for controlled deployments |

## Platforms
AWS · Azure · GCP · Terraform
