# S04 · UTM and Threat Prevention Rollout

**Customer:** Laugfs Gas Bangladesh (LPG / energy)
**Role:** Implementation and configuration

## Security objective
Add next-generation threat protection to an existing network and connect sites securely.

## Security controls delivered
| Control | Implementation |
|---|---|
| NGFW integration | **FortiGate 100E** integrated into the existing network infrastructure |
| Intrusion prevention | **IPS** sensors applied to firewall policies |
| Malware protection | **Antivirus** scanning of user traffic |
| Threat prevention | FortiGuard threat prevention services |
| Secure site connectivity | **Site-to-site IPsec VPN** |

## Platforms
Fortinet FortiGate 100E · FortiOS · FortiGuard
