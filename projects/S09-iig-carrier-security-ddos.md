# S09 · Carrier Gateway Security: IIG / ISP

**Company:** Earth Telecommunication (Pvt.) Ltd., International Internet Gateway, Dhaka
**Role:** Manager, Core Network (2013 – 2016)

## Security objective
Protect an international internet gateway, and the ISPs it serves, from attacks and outages while keeping traffic flowing.

## Security controls delivered
| Control | Implementation |
|---|---|
| Perimeter security | Firewalls protecting gateway infrastructure |
| Intrusion detection | Intrusion detection systems |
| **DDoS mitigation** | Detection and mitigation of volumetric attacks against the gateway and its customers |
| Routing security | Controlled BGP peering and routing policy with upstream and downstream networks |
| Monitoring | Traffic-pattern monitoring to spot anomalies and protect quality of service |
| Incident response | Troubleshooting and resolving outages and connectivity issues for IIG / ISP customers |

## Platforms
Juniper MX-480, MX-80, MX-10, MX-5 · Brocade VDX-6720 · BGP · MPLS
