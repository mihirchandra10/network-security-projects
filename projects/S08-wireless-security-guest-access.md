# S08 · Secure Enterprise Wireless and Guest Isolation

**Customer:** MAS Intimates Bangladesh (apparel manufacturing)
**Role:** Designed and implemented

## Security objective
Give staff resilient, authenticated wireless access, and give visitors internet-only access that stays separate from the corporate network.

## Security controls delivered
| Control | Implementation |
|---|---|
| Controller resilience | **HA** between Ruckus ZoneDirector 1200 controllers |
| Authentication | SSIDs configured with authentication security |
| Access control | ACLs restricting what wireless clients can reach |
| Guest access | **Token-based guest pass** so visitors get time-limited access, isolated from staff networks |

## Platforms
Ruckus ZoneDirector 1200 · Ruckus access points
